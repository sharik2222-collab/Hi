## LinkedIn Profile Improvements

Use this checklist to improve your LinkedIn profile:

- [ ] Add a professional profile photo and banner.
- [ ] Write a headline with your role + specialty + impact.
- [ ] Rewrite the About section with measurable achievements.
- [ ] Add experience bullets that focus on outcomes, not tasks.
- [ ] Add 5-10 relevant skills and request endorsements.
- [ ] Ask for 2-3 recommendations from managers or teammates.
- [ ] Turn on "Open to Work" or "Providing Services" (if applicable).
- [ ] Share one post per week about your work or learning.
